# @audiospan/sdk

Host API for loading and running Audiospan plugins in the browser. The AudioWorklet script is embedded; nothing to copy or serve.

```ts
import { AudiospanHost } from "@audiospan/sdk";
import type { LowpassPlugin } from "./plugins/lowpass.js";   // generated by `audiospan build`

const host = await AudiospanHost.create({ audioContext });    // from a user gesture
const plugin = await host.addPlugin<LowpassPlugin>("/plugins/lowpass/plugin.json"); // load + instance + chain
host.connectSource(source); host.connectDestination(audioContext.destination);
plugin.setParameter("cutoff", 440);                            // ids checked at compile time
```

`loadPlugin`, `createPlugin`, `createChain` and `connectChain` are the same steps individually. `@audiospan/sdk/testing` exposes `createInProcessRuntime()` to run the real runtime without a browser. `@audiospan/sdk/bundle` is a single-file ESM build for buildless pages; `@audiospan/sdk/worklet` is the worklet file for hosts whose Content Security Policy forbids `blob:` scripts (`workletUrl`).

Docs: [host integration](../../docs/host-integration.md), [web app integration](../../docs/web-app-integration.md).
