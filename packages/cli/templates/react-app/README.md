# __PLUGIN_NAME__ app

A Vite + React app generated by `audiospan create --app react`, wired to the plugin project in `__PLUGIN_DIR__`.

```sh
npm install
npm run plugin      # audiospan build --root __PLUGIN_DIR__ → public/plugins/__PROJECT_NAME__/ and src/plugins/__PROJECT_NAME__.d.ts
npm run dev         # then click "Start audio"
```

`src/audiospan/__COMPONENT_NAME__.tsx` is the integration: `useAudiospanHost` owns the AudioContext and host, `usePlugin` loads the plugin into the chain with compile-time checked ids, `useAudioSource` connects the microphone, and the controls and meters are React components from `@audiospan/react`. Edit it freely; it is yours.

`npm run plugin:watch` serves the plugin's own sandbox and rebuilds it on every save; the app picks up the new `module.wasm` on reload.
