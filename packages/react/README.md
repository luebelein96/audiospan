# @audiospan/react

React hooks and components for Audiospan plugins. The only package a React app needs: it re-exports `@audiospan/sdk` and `@audiospan/ui`, and the AudioWorklet script is embedded.

```sh
npx @audiospan/cli init --language cpp --name lowpass      # inside an existing React project
audiospan create lowpass --language cpp --app react        # or: a new plugin + a new Vite/React app
```

Both generate a component like this:

```tsx
import { Meters, ParameterControls, PresetSelect, useAudioSource, useAudiospanHost, usePlugin } from "@audiospan/react";
import type { LowpassPlugin } from "../plugins/lowpass.js";   // generated by `audiospan build`

export function Lowpass() {
  const audio = useAudiospanHost();                                           // owns the AudioContext and host
  const plugin = usePlugin<LowpassPlugin>(audio.host, "/plugins/lowpass/plugin.json"); // load + instance + chain, typed ids
  useAudioSource(audio, "microphone");                                        // or an <audio> element, stream, buffer, node, factory
  return (
    <>
      <button onClick={() => void audio.start()}>Start audio</button>        {/* audio starts from a gesture */}
      <ParameterControls plugin={plugin} /> <Meters plugin={plugin} /> <PresetSelect plugin={plugin} />
    </>
  );
}
```

| Export | Purpose |
| --- | --- |
| `useAudiospanHost(options)` | `{ host, audioContext, status, error, start, stop }`; creates and closes the `AudioContext` unless you pass one; passes host options through |
| `usePlugin<T>(host, source, options)` | `{ plugin, descriptor, status, error, values, outputs, bypassed, latencyFrames, setParameter, setParameterNormalized, setBypassed, loadPreset, reset }`; disposes on unmount; typed ids with a generated `T` |
| `useAudioSource(audio, source, options)` | Connects `"microphone"`, a `MediaStream`, an `HTMLMediaElement`, an `AudioBuffer`, an `AudioNode` or `(ctx) => node` while running; `{ status, error, node }` |
| `useParameter(plugin, id)`, `useOutput(plugin, id)` | Value, normalized position, setters, formatter and control model for your own components |
| `Knob`, `Slider`, `Toggle`, `Select`, `Stepper`, `ParameterControl`, `ParameterControls` | Controls bound to a plugin handle; same stylesheet as the default panel; `className` on all |
| `Meter`, `Meters`, `PresetSelect`, `BypassButton` | Output meters, presets, host-side bypass |
| `PluginPanel` | The complete default panel as a component |

Safe under StrictMode and hot reloading: each mount owns one plugin instance. Works as a Next.js client component (`"use client"`). Built on `createPluginStore` from `@audiospan/sdk`, a framework-neutral subscribe/getSnapshot store that other framework adapters can reuse.

Docs: [Web app integration](../../docs/web-app-integration.md), [From your DSP to a web app](../../docs/from-dsp-to-web.md).
