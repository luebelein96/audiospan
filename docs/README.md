# docs/

Internal planning documents: the product specification, the roadmap, the long-form feature backlog and the architecture decision records.

User-facing documentation lives in [`apps/docs/src/content/docs/`](../apps/docs/src/content/docs/), an Astro Starlight site published at https://luebelein96.github.io/audiospan/ by `.github/workflows/docs.yml`. Run `pnpm docs:dev` from the repository root to serve it locally.
